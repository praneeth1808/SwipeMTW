# SwipeMTW Logo Assets

This package was generated from the supplied JPEG reference.

## Use in Xcode
1. Open your SwiftUI project in Xcode.
2. In the Project Navigator, locate `Assets.xcassets`.
3. Replace the existing `AppIcon` set with:
   `02_Xcode/Assets.xcassets/AppIcon.appiconset`
4. Confirm the target's **App Icons Source** points to `AppIcon`.
5. Clean and rebuild the project.

## Primary file
`01_Master/SwipeMTW_AppIcon_Master_1024.png`

## Important production note
The source provided was a raster JPEG, not a vector master. These assets are therefore
high-quality raster derivatives. The icon also contains baked-in rounded corners and visual
effects from the supplied artwork. For the cleanest App Store result, commission or recreate
a true square, non-pre-rounded vector master and export a fresh 1024×1024 PNG.
